# Thư viện nhạc nền

Đặt các file nhạc **bạn có quyền sử dụng** vào đây (.mp3, .wav, .m4a...).

App chọn nhạc theo tên file, nên hãy đặt tên có chứa thể loại để AI khớp được, ví dụ:

- `lofi-chill-01.mp3`
- `edm-upbeat-hype.mp3`
- `piano-buon-nhe.mp3`
- `cinematic-epic-tension.mp3`

## Nguồn nhạc miễn phí bản quyền

- YouTube Audio Library (studio.youtube.com)
- Pixabay Music, Free Music Archive, Incompetech

Đọc kỹ điều kiện của từng bản nhạc: nhiều bản miễn phí vẫn yêu cầu ghi nguồn khi dùng thương mại.
